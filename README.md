# Pay-Go — Landing page Drake Digital

Ce dossier contient une page HTML statique prête pour GitHub Pages.

## Fichiers principaux

- `index.html` : page d'accueil à publier.
- `.nojekyll` : désactive le traitement Jekyll de GitHub Pages.
- `Background 2.png` : logo Drake Digital utilisé par le header.
- `Unblock img 1.jpg` : schéma de flux simplifié.
- `image3 app unblock.jpg` : visuel application mobile.
- `Unblock img 2.jpg` : visuel carte / paiement.

## Formulaire WhatsApp

Le formulaire n'envoie pas les données vers un serveur. Il ouvre WhatsApp avec un message prérempli vers : `+41 79 229 15 47`.
L'utilisateur doit ensuite valider l'envoi dans WhatsApp.
